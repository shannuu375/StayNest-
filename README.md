#  StayNest🌿 – PG & Hostel Management Website

**Tagline:** Your Home Away From Home.

## 📌 About the Project
StayNest is a simple and user-friendly PG and hostel management website designed to help students and working professionals find comfortable, safe, and affordable accommodation. It provides information about rooms, facilities, food menus, hostel rules, and contact details.

## 🎯 Objectives
- To display available rooms and their rental details.
- To provide information about hostel facilities.
- To show the weekly food menu.
- To make hostel rules and contact information easily accessible.
- To create a simple and attractive user experience.

## ✨ Features
- Attractive homepage
- Room details and pricing
- Facilities section
- Weekly food menu
- Hostel rules and guidelines
- Contact and support section
- Responsive webpage design

## 🛠️ Technologies Used
- **HTML5** – Structure of the website
- **CSS3** – Styling and layout
- **Google Fonts** – Typography
- **Unsplash** – Sample images

## 📂 Project Structure

## 🚀 How to Run
1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in any web browser.
4. Explore the StayNest🌿 website.

## 🎨 Design Theme
The website uses a natural colour palette with forest green, sage green, and cream to create a calm, welcoming, and comfortable appearance.
